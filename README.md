# General Theory of Cognitive Structuring (GTC)

Open formal framework for regulatory dynamics in cognitive architectures under bounded resources.

🔗 Interactive entry point: https://k-osmolovskyi.github.io/ 
📚 Full corpus: https://zenodo.org/communities/gtc  
🧪 Minimal simulation: `assets/trajectory_regulation_v2.py`

## Core Contribution

A substrate-independent regulatory stack separating:
- Geometric coherence ≠ Accessibility ≠ Representation ≠ Structural Updating
- Trajectory-dependent overload memory → hysteresis → admissibility boundary
- Pre-symbolic filtering → bias propagation → compressed invariants
- Identity as regulatory attractor, not self-model
- Inter-system co-regulation via order alignment, not metric equivalence
