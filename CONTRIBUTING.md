# GTCS

## Questions and discussion
- Do you have any questions about the content? Write to [constantinosmol@gmail.com]
- Found an inaccuracy in the wording? Create [Issue](https://github.com/k-osmolovskyi/k-osmolovskyi.github.io/issues) tagged `question`.

## Errors
- Typo, broken link, LaTeX compilation error?
- Create New Issue with the template:
  - Файл: `latex/core/axioms.tex`
  - Description: what's wrong
  - Suggestion: how to fix

## Suggestions for improvement
- Would you like to suggest a new example, or reference?
- Create New Issue tagged `enhancement`

## Paperwork
- Text: Use English quotation marks `''`, mathematics — in `$...$` or `$$...$$`
- References: DOI or arXiv ID preferred
